## 2026-10-31 ステップ2〜4：ゲームを完成させる

ユーザーから「試作ではなく完成まで止まらずに」との指示があり、ステップ2〜4をまとめて実装した。

### やったこと
- **シミュレーション本体**（`src/sim/`）：国民50人の効用ベースの行動決定、食料と物価、農民・商人・衛兵・弁護士・無職の経済、国庫と基本税、犯罪と摘発、即決裁判と裁判所、出生・移民・流出・餓死、暴動と革命、滅亡、文明レベル
- **条文パズル**：主語・条件・行動・結果の語彙（文明レベルで解放）、改正・廃止、法案トークン、「ひらめき」プリセット（悪法の例つき）
- **悪法のカオス**：ほふく前進、不眠、筆談、闇市、梨泥棒、夜警の消滅、訴訟社会、報酬ばらまき。統計から「号外」ニュースを自動生成
- **AI弁護士**：7種類の主張で条文の穴を突く。破られた穴を法典に表示し、対策のヒントを出す
- **判例レポート**：帰還時に放置中の出来事をダイジェスト表示。過去のレポートは判例集から読み返せる
- **画面**：国土ビュー（Canvas のドット絵、昼夜・文明レベルで建物が変化、国民タップで詳細）、法典・判例集・国民・統計・設定タブ、遊び方、建国やり直しと歴代の国
- **PWA**：マニフェスト、アイコン、サービスワーカー（オフライン動作）
- **テスト**：vitest 16件（条文の文章化、決定性、480ティック放置、ほふく前進、地下経済、不眠、弁護士、帰還レポート など）
- **公開**：GitHub Actions でテスト→ビルド→GitHub Pages へデプロイ

### 決めたこと
- 改正のクールダウンは、遊びやすさを優先して「法案トークン（最大3、3分で1回復）」に変更
- 画面を開いている間は速度を選べる（既定10倍）。放置計算は現実1分＝1時間のまま
- 調整した数値は設計書の付録Aにまとめた。`npm run balance` で代表的な法典を30日回して確認できる

### バランス確認の結果（30日・同じシード）
- 法なし：人口124、治安50前後、犯罪の波が続く → 法を作る動機になる
- 歩行に罰金：ほふく前進率98%、経済が半分に
- 睡眠に罰金：不眠と犯罪の波で幸福度が10台まで落ち、暴動へ
- 売買に100%課税：地下経済が60%前後で定着
- まっとうな法典（窃盗・暴力に投獄、商人に20%課税）：犯罪ほぼゼロ、国庫が黒字で安定
