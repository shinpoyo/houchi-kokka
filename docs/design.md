# ゲーム設計書：放置法治国家（仮）

> バージョン 1.0（2026-10-31）／ステータス：実装済み（付録Aに実装で決めた値をまとめた）

## 1. コンセプト

プレイヤーは新興国の「立法機関（または神）」。できるのは**法律を書くことだけ**で、国民を直接操作することは一切できない。法律を設定してアプリを閉じると、AIの国民たちが法の枠内で勝手に働き、罪を犯し、捕まり、裁判を起こし、社会を発展（あるいは崩壊）させていく。帰ってくると「判例・事件簿」で何が起きたかを知り、次の法改正に活かす。

### 体験の柱

| 柱 | 内容 |
|---|---|
| 立法パズル | 「主語＋行動＋結果」を組み合わせて条文を作る手触り |
| 放置の期待感 | 閉じている間に何が起きたか、帰還時に読むのが楽しみ |
| 副作用の驚き | 良かれと思った法が思わぬカオスを生む（悪法もまた法なり） |
| 知恵比べ | 文明が進むとAI弁護士が法の矛盾を突いてくる |

## 2. プラットフォームと技術前提

- **ブラウザで動くWebゲーム**（PC・スマホ両対応、縦画面優先のレスポンシブ）
- 言語：**TypeScript**、ビルド：**Vite**
- 描画：Canvas 2D（国民のドット表示）＋DOM（UI・レポート）
- **PWA**（ホーム画面に追加でアプリ風に起動、オフライン動作）
- 保存：`localStorage`（セーブデータはJSON。将来IndexedDBへ移行可）
- 公開：GitHub Pages
- シミュレーションは**描画から独立した純粋関数**として書く（テストしやすく、放置計算にそのまま使える）

## 3. ゲームループ

```
[立法フェーズ] 条文を作る/改正する
      ↓ アプリを閉じる（または放置）
[放置フェーズ] 経過時間ぶんシミュレーションを一括計算
      ↓ 再ログイン
[判例レポート] 事件簿ダイジェスト・指標の変化を表示
      ↓
[立法フェーズ] 次の改正へ
```

アプリを開いている間もリアルタイムで国民が動き（観察モード）、閉じている間は後述の「まとめ計算」で進む。

## 4. 立法システム（条文パズル）

### 4.1 条文の構造

```
条文 = 主語（誰が） ＋ 条件（いつ/どこで・任意） ＋ 行動（何をしたら） ＋ 結果（どうなる）
```

- 例：「夜間に＋労働した者は＋罰金100G」
- 例：「リンゴを＋盗んだ者は＋国外追放」
- 例：「農民が＋収穫したら＋報酬10G」

### 4.2 語彙（初期セット）

**主語**

| ID | 表示 | 対象 |
|---|---|---|
| `anyone` | 誰でも | 全国民 |
| `farmer` | 農民 | 職業=農民 |
| `merchant` | 商人 | 職業=商人 |
| `guard` | 衛兵 | 職業=衛兵 |
| `noble` | 貴族 | 資産上位10% |
| `poor` | 貧民 | 資産下位20% |
| `foreigner` | 外国人 | 移民 |

**条件（任意）**

| ID | 表示 |
|---|---|
| `night` | 夜間に |
| `day` | 日中に |
| `market` | 市場で |
| `street` | 路上で |
| `holiday` | 休日に |

**行動**

| ID | 表示 | 備考 |
|---|---|---|
| `work` | 労働した | 経済の基本行動 |
| `harvest` | 収穫した | 農民の生産 |
| `trade` | 売買した | 商人の生産 |
| `steal_apple` | リンゴを盗んだ | 軽犯罪 |
| `steal` | 盗みを働いた | 犯罪全般 |
| `assault` | 暴力をふるった | 重犯罪 |
| `walk` | 歩いた | カオス要素用 |
| `sleep` | 眠った | カオス要素用 |
| `speak` | 発言した | 言論統制系 |
| `immigrate` | 入国した | 人口系 |
| `sue` | 訴えた | 司法系 |

**結果**

| ID | 表示 | 種類 | パラメータ |
|---|---|---|---|
| `fine` | 罰金 | 罰則 | 金額 10〜1000G |
| `jail` | 投獄 | 罰則 | 日数 1〜30 |
| `exile` | 国外追放 | 罰則 | — |
| `death` | 死刑 | 罰則 | —（文明・幸福に大きな負荷） |
| `reward` | 報酬 | 報酬 | 金額 |
| `tax` | 課税 | 経済 | 税率 0〜100% |
| `ban` | 禁止（罰則なし） | 規範 | — |

> 組み合わせは自由。意味が通らない条文（「眠った者に報酬」など）も**あえて許可**し、カオスの種にする。

### 4.3 法律の上限と解放

- 初期は条文スロット3つ。文明レベルで増える（最大12程度）。
- 語彙も文明レベルで解放（例：`sue` は文明Lv3、`speak` は文明Lv4）。
- 改正にはクールダウン（例：現実時間で10分）を設け、放置を促す。

### 4.4 内部表現（案）

```ts
type Law = {
  id: string;
  subject: SubjectId;
  condition?: ConditionId;
  action: ActionId;
  outcome: { type: OutcomeId; amount?: number };
  enactedAt: number; // ゲーム内日
};
```

## 5. 国民（AIエージェント）

### 5.1 パラメータ

| パラメータ | 範囲 | 説明 |
|---|---|---|
| `job` | 農民/商人/衛兵/無職/弁護士… | 主な行動を決める |
| `money` | 0〜 | 所持金（G） |
| `hunger` | 0〜100 | 高いほど盗みに傾く |
| `happiness` | 0〜100 | 低いと国外流出・暴動 |
| `lawfulness` | 0〜100 | 遵法精神。法を守る確率に影響 |
| `greed` | 0〜100 | 抜け穴を探す傾向（悪徳商人の素） |
| `fear` | 0〜100 | 罰則の重さへの反応度 |
| `intelligence` | 0〜100 | 抜け穴発見・弁護士化の素質 |
| `status` | 自由/投獄/追放/死亡 | |
| `record` | 前科リスト | 判例レポートのネタ |

### 5.2 行動決定（効用ベース）

国民は毎ティック、取りうる行動それぞれに「期待効用」を計算して最大のものを選ぶ（＋少しのランダム）。

```
効用 = 行動の利得（お金・満腹・幸福）
     − 法の期待コスト（罰則の重さ × 摘発確率 × fear）
     + 個性補正（greed, lawfulness）
```

- 摘発確率は「衛兵の数 ÷ 人口」と条件（夜間は低い等）で決まる。
- 法が禁止した行動の**代替行動**を探す（歩行禁止→ほふく前進、売買課税100%→物々交換・闇市）。これが「悪法のカオス」の仕組み。

### 5.3 人口の増減

- 増加：出生（幸福度が高いと増）、移民（`immigrate` を罰しなければ流入）
- 減少：餓死、国外追放、死刑、国外流出（幸福度が低い）

## 6. 国家指標

| 指標 | 計算の元 | 影響 |
|---|---|---|
| 人口 | 国民数 | 生産力・文明 |
| 経済（GDP） | 1日の生産と取引の合計 | 税収・文明 |
| 国庫 | 罰金・税収 − 衛兵給与・報酬 | 報酬型の法を維持できるか |
| 治安 | 犯罪件数の逆数、衛兵比率 | 幸福度 |
| 幸福度 | 国民の平均 happiness | 人口の増減 |
| 自由度 | 有効な禁止法の数・重さの逆数 | 幸福度・文明 |
| 地下経済 | 違法取引の割合 | カオス演出 |
| 文明レベル | 経済・人口・時間の累積 | 語彙・スロット・弁護士の解放 |

国が崩壊する条件：人口0、または国庫破綻＋暴動。崩壊したら「建国やり直し」（過去の判例は歴史として残す）。

## 7. 放置進行の仕組み

- セーブデータに `lastSavedAt`（現実時刻）を記録する。
- 起動時に `経過時間 = 現在 − lastSavedAt` を求め、**ゲーム内日数に換算**してまとめて計算する。
  - 換算レート（案）：現実1分 ＝ ゲーム内1時間（1日＝24分）
  - 上限：最大8時間ぶん（＝ゲーム内20日）。それ以上は切り捨て（「国民が神の不在に慣れた」と表示）
- まとめ計算は1ティック＝ゲーム内1時間。描画なしで回すので高速。重い場合は日単位の集計モードに切り替える。
- 乱数は**シード付き**にする（同じ状態から同じ結果になり、バグ再現・テストが容易）。
- 計算中に起きた事件は**イベントログ**に記録し、判例レポートの材料にする。

## 8. 判例レポート（帰還時）

- 帰還時に「神が不在だった○日間」のダイジェストを表示。
- 内容：
  1. **指標の変化**（人口・経済・治安・幸福度の増減）
  2. **注目判例 3〜5件**：イベントログから「面白さスコア」の高いものを選ぶ
  3. **ひとことニュース**（「ほふく前進ブーム、膝当ての売上が急増」等）
- 面白さスコアの例：初めての出来事、極端な刑罰、抜け穴の発見、大金の移動、弁護士の勝訴。
- 判例文はテンプレート＋変数で生成（AI APIは使わずオフラインで動かす）。
  - 例：「【第12号判例】商人トマスは『リンゴを盗んだ者は国外追放』の条文に対し、盗んだのは『梨』であると主張。無罪。」

## 9. 悪法のカオス（ユニーク要素1）

極端な法に対して国民が**代替行動**をとり、見た目と社会が変化する。

| 法律 | 国民の反応 | 見た目 |
|---|---|---|
| 誰でも＋歩いた＋禁止 | 全員ほふく前進、移動速度低下→生産低下 | 這うスプライト |
| 誰でも＋売買した＋課税100% | 物々交換・闇市が発達、地下経済↑ | 路地裏に露店 |
| 誰でも＋眠った＋罰金 | 不眠国家、幸福度↓、夜も活動 | 目の下にクマ |
| 誰でも＋発言した＋投獄 | 筆談・ジェスチャー文化 | 吹き出しが「…」 |
| 夜間に＋労働した＋罰金 | 夜警がいなくなる→夜の犯罪↑ | 夜の街が暗い |
| リンゴを盗んだ＋国外追放 | 犯罪↓だが人口激減 | 国境に行列 |

実装方針：行動ごとに「代替行動」テーブルを持ち、元の行動が禁止されると代替に切り替える。代替行動には効率ペナルティと見た目フラグを付ける。

## 10. AI弁護士（ユニーク要素2）

- **出現条件**：文明レベル3以上、`intelligence` が高い国民から一定確率で「弁護士」に転職。
- **裁判の流れ**：逮捕 → 裁判 → 弁護士がいれば弁護 → 判決。
- **弁護士が突く矛盾の種類**（条文の構造から機械的に判定できるものに絞る）：

| 種類 | 例 |
|---|---|
| 対象外の主張 | 「農民が盗んだら罰」→被告は元農民の無職 |
| 条件外の主張 | 「夜間に〜」→犯行は夕暮れ（境界時間） |
| 目的語のずれ | 「リンゴを盗んだ」→盗んだのは梨 |
| 法の衝突 | 「収穫したら報酬」と「労働したら罰金」が同時に当てはまる |
| 遡及の否定 | 行為が法の制定前 |

- 弁護士の勝率は `intelligence` と条文の「穴の多さ」で決まる。勝訴は判例として記録され、プレイヤーは条文を具体的にする（条件を足す、主語を広げる）ことで対抗する。
- 弁護士が増えすぎると訴訟社会化（`sue` の乱発、経済停滞）というカオスも用意する。

## 12. 画面構成（スマホ縦基準）

1. **国土ビュー**：国民がうろつく俯瞰ドット絵。上部に指標バー。
2. **法典**：現在の条文一覧と、条文パズル（主語・条件・行動・結果のカードを選ぶ）。
3. **判例集**：過去のレポートと判例のアーカイブ。
4. **帰還レポート**：起動時にモーダル表示。

PCでは国土ビューと法典を横並びにする。
