# 放置法治国家

法律を作って、人々がどうするかを眺める放置型国家運営シミュレーション。

プレイヤーは新興国の「立法機関（または神）」。「主語＋条件＋行動＋結果」のパズルで条文を作ってアプリを閉じると、AIの国民たちが法に従って（あるいは抜け穴を突いて）勝手に働き、罪を犯し、裁判を起こします。帰ってくると、放置中の判例・事件簿が待っています。

**遊ぶ**：https://shinpoyo.github.io/houchi-kokka/ （PC・スマホのブラウザ。ホーム画面に追加するとアプリのように起動し、オフラインでも遊べます）

## 特徴

- **条文パズル**：「夜間に＋労働した＋者は＋罰金100G」のように語彙を組み合わせて法律を作る。意味の通らない条文もあえて作れる
- **放置進行**：現実1分＝ゲーム内1時間。閉じている間も最大8時間ぶん（ゲーム内20日）国民が暮らす
- **判例レポート**：帰還時に、指標の変化・号外・注目の判例をダイジェスト表示
- **悪法もまた法なり**：歩行を罰すれば全員ほふく前進、睡眠を罰すれば不眠国家、売買に100%課税すれば地下経済が爆誕
- **AI弁護士**：文明Lv3から弁護士が現れ、「盗んだのはリンゴではなく梨」「犯行は夕暮れで夜間ではない」など条文の穴を突いて無罪を勝ち取る。破られた穴は法典に表示される
- **文明レベル**：集落→村→町→都市→国家。語彙と条文の枠が増える
- 暴動・革命・滅亡、建国やり直し（歴代の国は歴史に残る）

## 開発

```bash
npm install
npm run dev       # 開発サーバー
npm test          # シミュレーションのテスト
npm run build     # 型チェック＋本番ビルド（dist/）
npm run balance   # 代表的な法典で30日回してバランスを確認
```

- TypeScript / Vite / Canvas 2D、外部ライブラリなし
- `src/sim/`：描画から独立したシミュレーション（シード付き乱数で決定的）
- `src/ui/`：国土ビュー（ドット絵）と各タブの画面
- `src/game/save.ts`：localStorage 保存と放置時間の計算
- `public/sw.js`：オフライン対応のサービスワーカー
- main ブランチへのpushで GitHub Actions がテスト・ビルドして GitHub Pages に公開
