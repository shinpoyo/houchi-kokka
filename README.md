# 放置法治国家（仮）

法律を作って、人々がどうするかを眺める放置型国家運営シミュレーション。

プレイヤーは新興国の「立法機関（または神）」。「主語＋行動＋結果」のパズルで条文を作ってアプリを閉じると、AIの国民たちが法に従って（あるいは抜け穴を突いて）勝手に働き、罪を犯し、裁判を起こします。帰ってくると、放置中の判例・事件簿が待っています。

- 対応：PC・スマホのブラウザ（PWA）
- 技術：TypeScript / Vite / Canvas 2D
